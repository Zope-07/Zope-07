## 👋 A little about me

I enjoy the point where **raw data becomes something people can actually use** — a query engine, a dashboard, a prediction, or a cleaner decision.

- 🧩 I like connecting the whole journey: ingestion → transformation → analytics → user experience.
- ☁️ My recent work has pushed me deeper into cloud data platforms, distributed processing, and automation.
- 🛠️ My mechanical-engineering background gave me a process-first mindset; data engineering gave me a new place to apply it.
- 🎓 I am currently completing PG-DBDA and building stronger foundations across data engineering, BI, and machine learning.
- 🤝 Open to learning, collaboration, and opportunities where I can build useful data products.
